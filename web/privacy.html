새봄 다이어리 v0.1.0 · 2026-10-12

체중·체성분·일정·회사 데이터는 브라우저 또는 앱 내부 저장 공간에 저장합니다. 로그인, 광고, 분석 도구, 클라우드 동기화가 없으며 앱이 신체 기록을 서버로 전송하지 않습니다.

Android APK에는 인터넷·카메라·위치·연락처·광범위한 저장소 접근 권한이 없습니다. 백업 저장과 가져오기는 사용자가 선택한 파일에만 접근하는 시스템 파일 선택창을 사용합니다.

앱 삭제 또는 브라우저 데이터 삭제 시 기록이 삭제될 수 있습니다. 설정에서 JSON 백업을 저장하고 기기를 옮길 때 가져오세요. PC 웹 버전과 휴대폰 앱의 기록은 자동으로 공유되지 않습니다.

GitHub Pages 접속 시 호스팅 제공자가 일반적인 접속 정보를 처리할 수 있습니다. 선택해 내보낸 백업 파일은 사용자가 직접 보관합니다.
